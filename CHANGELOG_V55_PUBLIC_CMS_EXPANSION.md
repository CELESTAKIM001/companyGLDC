# GLDC V55 — Public CMS Expansion

- Added Admin Public Pages Editor for About, Services and Projects.
- About supports unlimited sections and multiple Drive image codes per section.
- Services supports editable cards, unlimited services, multiple Drive images and visual effects.
- Projects page supports editable background images, published public projects and unlimited project galleries.
- Insights page supports background image settings and external read-more links on individual insights.
- Added public Subscribe page and Message page.
- Added admin Website Inbox for subscribers and website messages.
- Website messages also create CRM leads for follow-up.
- All public images use existing GLDC Drive image codes and server-side publication checks.
