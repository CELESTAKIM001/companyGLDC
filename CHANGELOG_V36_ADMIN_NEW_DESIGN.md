# V36 — Admin Console New Design

- Rebuilt the authenticated admin shell as a dedicated application layout.
- Fixed sidebar/content geometry with a fixed desktop navigation rail and fluid workspace.
- Removed reliance on inherited public-site layout rules.
- Only the active admin view is rendered; inactive views are forced out of layout.
- Added modern top bar, KPI cards, panels, tables, forms, responsive breakpoints, and modal styling.
- Wide tables scroll inside their own containers instead of changing page width.
- Preserved existing admin routes, JavaScript loaders, membership, payment, certificate, CRM, Drive, CMS and settings functionality.
